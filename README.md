# Soinver Ingeniería — Página informativa

Sitio web informativo de **Soinver Ingeniería S.A.** basado en el dossier de capacidades 2026.

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Contenido

Incluye secciones de la empresa: quiénes somos, misión y visión, organización, flota, trayectoria vial, minería, obra civil, energía, equipo, seguridad, innovación, cartera activa, acreditaciones, alianzas y contacto.
